# سایت شخصی — رزومه، نمونه‌کار و مقالات (الکترونیک) ⚡

سایت کامل با **فرانت‌اند** و **بک‌اند (پنل مدیریت)** — تم دارک امروزی، کاملاً ریسپانسیو و **دوزبانه (فارسی / انگلیسی)**.
بعد از نصب، برای هر تغییری **اصلاً به کدنویسی نیاز نیست**.

## ✨ امکانات

**صفحات عمومی:**
- 🏠 صفحه اصلی: Hero با نشان «در دسترس برای پروژه‌ها»، آمار متحرک، کارهای منتخب، آخرین مقالات
- 👤 «درباره من / رزومه»: خود معرفی، تحصیلات، سوابق کاری، مهارت‌ها، دانلود رزومه PDF
- 🖼️ «نمونه‌کارها»: کارت‌های پروژه با دسته‌بندی و فیلتر + صفحه جزئیات
- 📚 «مقالات علمی»: گروه‌بندی سال، جستجوی زنده (دو زبان)، فیلتر نوع، DOI و PDF
- ✉️ «تماس»: فرم ایمیل + راه‌های ارتباطی

**دو زبانه (FA / EN):**
- 🌐 دکمه تغییر زبان در هدر (با یک کلیک؛ انتخاب کاربر ۱ سال ذخیره می‌شود)
- تمام متن‌های محتوا (تیتر، توضیحات، تحصیلات، سوابق، مقالات) **به هر دو زبان** از پنل مدیریت وارد می‌شوند
- راست‌چین/چپ‌چین و فونت‌ها (Vazirmatn / Inter) خودکار با زبان عوض می‌شوند
- اگر متنی به یکی از زبان‌ها خالی بماند، به‌صورت خودکار از زبان دیگر نمایش داده می‌شود

**پنل مدیریت `/admin`:**
- 🔐 رمز عبور (در اولین ورود ساخته می‌شود) + قفل موقت بعد از ۶ تلاش اشتباه
- 📝 ویرایش محتوا با فرم‌های دوزبانه (هر فیلد یک نسخه فارسی و یک نسخه انگلیسی)
- 🖼️ مدیریت نمونه‌کار + 📚 مدیریت مقالات (آپلود عکس و PDF)
- ⚙️ تنظیمات شخصی، لینک‌های GitHub/LinkedIn/ORCID/Scholar/Telegram، رزومه PDF، تغییر رمز
- 🗄️ بدون دیتابیس: همه‌چیز در یک فایل JSON

## 🚀 نصب — فقط ۳ قدم

1. **آپلود کد:** `website.zip` را در cPanel → File Manager → `public_html` آپلود و **Extract** کنید (یا با FTP محتویات زیپ را داخل پوشه بریزید).
2. **ساختن رمز پنل:** آدرس `https://yourdomain.com/admin` را باز کنید و یک رمز عبور (حداقل ۸ کاراکتر) انتخاب کنید.
3. **پر کردن محتوا:** از پنل، مشخصات خود را جایگزین محتوای نمونه کنید:
   - ⚙️ **تنظیمات**: نام، عکس، ایمیل، تلگرام/ORCID/Scholar، **رزومه PDF**
   - 📝 **ویرایش محتوا**: تیتر و معرفی (فارسی + انگلیسی)، تحصیلات، سوابق، مهارت‌ها
   - 🖼️ **نمونه‌کارها**: پروژه‌ها (مثلاً طراحی PCB، BMS، درایور موتور، IoT)
   - 📚 **مقالات علمی**: عنوان دو زبانه، DOI، PDF

## 💡 نمونه‌کارهای رایج حوزه الکترونیک (ایده برای پر کردن)

- طراحی PCB (KiCad/Altium) — برد سنسور IoT، برد ماژول، برد صنعتی
- الکترونیک قدرت — BMS، منبع تغذیه سوئیچینگ، اینورتر، شارژر
- سیستم‌های تعبیه‌شده — پروتوتایپ با ESP32/STM32، فریم‌ور، سنسورها
- IoT و الکترونیک صنعتی — دستگاه مانیتورینگ، SCADA، اتوماسیون
- کنترل موتور — درایور BLDC/DC، FOC، رباتیک
- RF و مخابرات — آنتن، طراحی فرکانس بالا، ماژول‌های ارتباطی
- تعمیرات و تحلیل عیب‌یابی — مستندسازی تعمیر برد/دستگاه

## 📌 نکات مهم

- **HTTPS/SSL**: در cPanel از AutoSSL گواهی رایگان فعال کنید.
- **زبان پیش‌فرض**: فارسی است؛ با کلیک روی 🌐 EN در هدر، سایت انگلیسی می‌شود (برای مهمان انگلیسی‌زبان هم همان لینک با `?set_lang=en`).
- **ایمیل فرم تماس**: اگر `mail()` روی هاست غیرفعال باشد، سایت خودش راهنمایی می‌دهد که مستقیم برای ایمیل شما بنویسند.
- **بکاپ**: کپی پوشه‌های `data` و `uploads` بکاپ کامل است.
- **حجم آپلود**: پیش‌فرض ۱۰ مگابایت؛ برای فایل بزرگ‌تر `upload_max_filesize` و `post_max_size` را در cPanel بالا ببرید.
- **فراموشی رمز**: فایل `data/auth.json` را پاک کنید تا دوباره رمز بسازید (محتوا حذف نمی‌شود).

## 🧯 اگر خطا دیدم

| مشکل | راه‌حل |
|---|---|
| صفحه 500 | خط `Options -Indexes` در `.htaccess` را موقتاً پاک کنید یا `AllowOverride All` را فعال کنید |
| `/about` و... باز نمی‌شود | mod_rewrite باید فعال باشد (در cPanel پیش‌فرض فعال است) |
| آپلود خطا می‌دهد | `upload_max_filesize`/`post_max_size` را بالا ببرید |
| فونت خوب نیست | فونت‌ها از Google Fonts لود می‌شوند؛ بدون اینترنت، فونت سیستم جایگزین می‌شود |
| جابجایی سایت | فقط همه فایل‌ها را کپی کنید |

## 🔒 امنیت

- رمز عبور با bcrypt هش می‌شود • فرم‌ها با CSRF token محافظت شده‌اند
- خروجی‌ها Escape می‌شوند (XSS) • اجرای اسکریپت در `uploads` غیرفعال است
- پوشه `data` از وب مسدود است • Session با `HttpOnly` + `SameSite=Lax`
- قفل موقت IP بعد از ۶ تلاش ورود ناموفق (۱۵ دقیقه)
