## 🌟 معرفی پروژه و امکانات ویژه

این وب‌اپلیکیشن، یک **پورتفولیو پیشرفته و سیستم مدیریت محتوای جامع (CMS)** اختصاصی مهندسان الکترونیک، طراحان بردهای مدار چاپی فرکانس بالا (High-Speed PCB)، توسعه‌دهندگان سیستم‌های امبدد (Embedded / RTOS) و پژوهشگران سخت‌افزار است. 

### 💎 ویژگی‌های بارز:
* **چیدمان کاملاً داینامیک و محاسبه خودکار سقف اقلام ($\text{Rows} \times \text{Cols}$):** تعیین تعداد ردیف‌ها (۱، ۲ یا ۳ ردیف) و تعداد ستون‌ها (۱، ۲، ۳ یا ۴ ستون در دسکتاپ) برای بردها و مقالات با دکمه بازشونده انیمیشنی «مشاهده بیشتر / کمتر».
* **پورتال وبلاگ تخصصی مهندسی (Tech Blog):** محیط مستقل مطالعه و انتشار مقالات با ادیتور غنی مشابه مایکروسافت ورد، فیلتر موضوعی، لایک‌های انیمیشنی جشنی و پخش‌کننده پادکست‌های صوتی اختصاصی.
* **شبیه‌ساز سه‌بعدی و چرخش ۳۶۰ درجه بردها (3D Interactive PCB):** قابلیت چرخش ۳۶۰ درجه در تمام جهات، زوم، تعویض رنگ چاپ محافظ (سبز، مشکی مات، آبی، بنفش، قرمز) با **حفاظت کامل View-Only** (غیرفعال بودن دانلود مستقیم فایل‌های CAD/STEP و عکس‌ها جهت حفظ مالکیت معنوی).
* **فیلدهای دوزبانه زیر هم در پنل مدیریت:** در تمامی فرم‌های مدیریت (اطلاعات فردی، بردها، مقالات، مهارت‌ها، سوابق و وبلاگ)، فیلد معادل انگلیسی دقیقاً در زیر فیلد فارسی قرار دارد تا امکان ورود دستی و سفارشی متون انگلیسی فراهم باشد.
* **سیستم مدیریت دسترسی چندکاربره (RBAC):** ۶ نقش (مدیر ارشد، مدیر سیستم، ویرایشگر محتوا، نویسنده/مهندس، ناظر فقط‌خواندنی و سفارشی) با ماتریس تفکیکی ۱۱ مجوزه، محافظت از ادمین اصلی و پیام‌های صادقانه قفل/محدودیت.
* **۵۰ تم و قالب زنده صفحه اول:** قابل انتخاب و تغییر فوری از داخل پنل مدیریت بدون هیچ‌گونه بنر تبلیغاتی یا المان مزاحم در بخش عمومی.
* **مرکز فویکون، برندینگ و سئو:** امکان آپلود آیکون تب مرورگر (Favicon) با تبدیل خودکار به Data URI، انتخاب از بین ۶ آیکون آماده مهندسی، شبیه‌ساز تب مرورگر و تنظیم متاتگ‌های دوزبانه گوگل.
* **تولید خروجی رزومه استاندارد به فرمت PDF:** دانلود مستقیم رزومه کاری در ۳ قالب شیک به زبان‌های فارسی یا ۱۰۰٪ انگلیسی.

## 💻 راهنمای گام‌به‌گام نصب، اجرا و تست روی کامپیوتر شخصی (Localhost)

اگر می‌خواهید پروژه را روی کامپیوتر شخصی خود (ویندوز، مک یا لینوکس) اجرا کرده، تغییرات را آزمایش و محتوای خود را قبل از آپلود بررسی کنید، مراحل زیر را به ترتیب انجام دهید:

### مرحله ۱: پیش‌نیازها
ابتدا مطمئن شوید نرم‌افزار **Node.js** (نسخه ۱۸ به بالا) روی سیستم شما نصب است:
* برای دانلود Node.js به وبسایت رسمی [nodejs.org](https://nodejs.org) رفته و نسخه **LTS** را دانلود و نصب کنید.
* برای اطمینان از نصب، ترمینال (یا Command Prompt در ویندوز) را باز کرده و تایپ کنید:
```bash
node -v
npm -v
```

### مرحله ۲: باز کردن پوشه پروژه
پوشه پروژه `resume-app` را در ترمینال یا محیط VS Code باز کنید:
```bash
cd /path/to/resume-app
```

### مرحله ۳: نصب پکیج‌ها و وابستگی‌ها
دستور زیر را اجرا کنید تا تمام کتابخانه‌ها در عرض چند ثانیه نصب شوند:
```bash
npm install
```

### مرحله ۴: اجرای سرور توسعه محلی (Dev Server)
دستور زیر را برای راه‌اندازی سرور تست اجرا کنید:
```bash
npm run dev
```

### مرحله ۵: باز کردن در مرورگر و تست
پس از اجرای دستور، آدرس زیر را در مرورگر خود باز کنید:
```text
http://localhost:5173
```
* **ورود به پنل مدیریت:** روی آیکون قفل در فوتر یا دکمه «ورود به پنل مدیریت» کلیک کنید.
* **نام کاربری پیش‌فرض:** `admin`
* **کلمه عبور پیش‌فرض:** `admin`
* شما می‌توانید تمام فیلدها، ۵۰ قالب، مقالات، وبلاگ، بردهای الکترونیکی و چیدمان‌ها را آزادانه ویرایش و تست فرمایید.

## 🌐 راهنمای گام‌به‌گام استقرار روی هاست واقعی و اتصال دامنه اختصاصی

این پروژه به صورت **Single Page Application (SPA)** ساخته شده است؛ برای اجرا روی هاست **به هیچ‌گونه سرور NodeJS یا دیتابیس MySQL نیاز ندارد** — بک‌اند واقعی (احراز هویت، ایمیل، بک‌آپ) با **PHP خالص و ذخیره فایلی** کار می‌کند و روی ارزان‌ترین هاست‌های لینوکسی اشتراکی (cPanel / DirectAdmin / Plesk) بالا می‌آید.

> ✅ **روش پیشنهادی استقرار:** فایل آماده **`site-upload.zip`** (ریشه ریپو — شامل فرانت بیلدشده + بک‌اند `api/`) را در `public_html` اکسترکت کنید؛ سپس یک رفرش سنگین (`Ctrl+Shift+R`) بزنید. راهنمای تصویری قدم‌به‌قدم: **[QUICK_DEPLOY_FA.md](QUICK_DEPLOY_FA.md)**. بخش‌های بعدی این فصل، روش دستی (بیلد محلی) را توضیح می‌دهند.

---

### بخش الف) خروجی نهایی گرفتن از پروژه (Build)
در پوشه پروژه روی کامپیوتر خود دستور زیر را اجرا کنید:
```bash
npm run build
```
این دستور پوشه‌ای به نام **`dist`** در ریشه پروژه ایجاد می‌کند که حاوی تمام فایل‌های HTML، CSS بهینه‌شده، کدهای فشرده جاوااسکریپت و تصاویر است.

---

### بخش ب) آپلود روی هاست اشتراکی (cPanel / DirectAdmin)
1. وارد کنترل پنل هاست خود (cPanel یا DirectAdmin) شوید.
2. به بخش **File Manager** (مدیریت فایل) بروید.
3. وارد پوشه **`public_html`** شوید (اگر فایلی از قبل وجود دارد آن را حذف یا خالی کنید).
4. تمام فایل‌ها و پوشه‌های داخل پوشه **`dist`** را زیپ کنید (`dist.zip`).
5. فایل `dist.zip` را داخل `public_html` آپلود کرده و سپس **Extract** (خارج کردن از حالت فشرده) نمایید.
6. دقت کنید که فایل `index.html` مستقیماً درون پوشه `public_html` قرار گیرد (نه داخل یک زیرپوشه اضافه).

---

### بخش ج) فایل پیکربندی `.htaccess` (مسیریابی SPA و کش سریع)
یک فایل به نام **`.htaccess`** به صورت خودکار در داخل خروجی `dist` تعبیه شده است. این فایل تضمین می‌کند که رفرش صفحات و مسیریابی بدون ارور ۴۰۴ انجام شده و فشرده‌سازی Gzip برای سرعت لود زیر ۱ ثانیه در اینترنت ایران فعال باشد:
```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>

# Gzip Compression for Ultra-Fast Loading
<IfModule mod_deflate.c>
  AddOutputFilterByType DEFLATE text/html text/plain text/xml text/css application/javascript application/json image/svg+xml
</IfModule>

# Browser Cache Control
<IfModule mod_expires.c>
  ExpiresActive On
  ExpiresByType image/jpg "access plus 1 year"
  ExpiresByType image/jpeg "access plus 1 year"
  ExpiresByType image/png "access plus 1 year"
  ExpiresByType image/svg+xml "access plus 1 year"
  ExpiresByType text/css "access plus 1 month"
  ExpiresByType application/javascript "access plus 1 month"
</IfModule>
```

---

### بخش د) اتصال دامنه اختصاصی (دامنه .ir یا .com)
1. وارد پنل مدیریت دامنه خود (مانند ایرنیک [nic.ir](https://www.nic.ir) برای دامنه‌های `.ir` یا پنل رجیسترار دامنه بین‌المللی) شوید.
2. **تنظیم نیم‌سرورها (NameServers):** نیم‌سرورهای هاست خود را (که در ایمیل مشخصات هاست ارسال شده، مثلاً `ns1.yourhost.ir` و `ns2.yourhost.ir`) در فیلدهای مربوطه ثبت کنید.
3. در صورتی که هاست ابری یا سرور مجازی دارید، یک **A Record** با نام `@` و مقدار IP سرور خود تعریف نمایید.
4. انتشار DNS برای دامنه‌های بین‌المللی معمولاً بین ۱۰ دقیقه تا ۲ ساعت و برای دامنه‌های ملی `.ir` بین ۴ تا ۱۲ ساعت زمان می‌برد.

---

### بخش ه) فعال‌سازی رایگان SSL (پروتکل امن HTTPS)
1. در پنل هاست خود وارد بخش **SSL/TLS Status** یا **Let's Encrypt SSL** شوید.
2. دامنه خود را انتخاب کرده و روی **Issue** یا **Run AutoSSL** کلیک کنید.
3. پس از چند ثانیه، گواهینامه امنیتی SSL به رایگان فعال شده و سایت شما با آدرس امن `https://yourdomain.ir` باز خواهد شد.

---

### بخش و) استقرار روی سرور مجازی (VPS) یا سرورهای لینوکس با NGINX (اختیاری)
اگر پروژه را روی VPS یا سرور اختصاصی ابری لینوکس (Ubuntu/Debian) میزبانی می‌کنید، از کانفیگ استاندارد زیر استفاده فرمایید:
```nginx
server {
    listen 80;
    server_name yourdomain.ir www.yourdomain.ir;
    root /var/www/yourdomain.ir/dist;
    index index.html;

    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml image/svg+xml;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~* \.(jpg|jpeg|png|gif|ico|css|js|woff2|svg)$ {
        expires 365d;
        add_header Cache-Control "public, no-transform";
    }
}
```

## 🔐 راهنمای ورود به پنل مدیریت و سیستم کنترل دسترسی کاربران (RBAC)

* **دسترسی سریع:** روی دکمه مدیریت یا آیکون قفل در پایین سایت کلیک کنید.
* **حساب کاربری ریشه (پیش‌فرض):**
  * **نام کاربری:** `admin`
  * **رمز عبور:** `admin`
* **سطوح دسترسی موجود در سیستم (۶ نقش + ۱۱ مجوز):**
  1. **مدیر ارشد (`super_admin`):** دسترسی کامل به همه‌چیز از جمله امنیت، کاربران و بک‌آپ‌ها.
  2. **مدیر سیستم (`admin`):** مدیریت روزمره بدون بخش‌های حساس ریشه.
  3. **ویرایشگر محتوا (`editor`):** مدیریت وبلاگ، مقالات و اطلاعات نمایشی.
  4. **نویسنده / مهندس (`author`):** ثبت و ویرایش بردها، مقالات و مشخصات فنی.
  5. **ناظر (`viewer`):** فقط‌خواندنی، بدون امکان ویرایش.
  6. **سفارشی (`custom`):** فعال‌سازی دستی هر یک از ۱۱ مجوز.
* **نکته ورود:** روی هاست واقعی (حالت امن 🔒) رمز پیش‌فرض وجود ندارد و ویزارد نصب باز می‌شود؛ `admin` / `admin` فقط برای حالت محلی/لوکال‌هاست است.

## ⚙️ راهنمای تنظیمات کلان، فویکون و چیدمان داینامیک

تمامی پیکربندی‌های کلان در پنل ادمین زیر برگه یکپارچه **«تنظیمات کلان سایت»** قرار دارند:

| زیربرگه تنظیمات | کاربرد و امکانات |
|---|---|
| **چیدمان و ردیف‌ها (`layout`)** | تنظیم تعداد ردیف‌ها (۱، ۲ یا ۳) و ستون‌ها (۱، ۲، ۳ یا ۴) بردهای الکترونیکی و مقالات با محاسبه خودکار سقف |
| **فویکون و برندینگ (`branding`)** | آپلود آیکون تب مرورگر، انتخاب از ۶ آیکون آماده، شبیه‌ساز زنده تب، نام تجاری و کپی‌رایت فوتر |
| **مدیریت کاربران (`users`)** | تعریف کاربران جدید، ویرایش نقش‌ها، تعیین رمز عبور و ماتریس دسترسی ۱۰ مجوزه |
| **۵۰ قالب و تم (`design`)** | انتخاب و سوئیچ آنی بین ۵۰ مدل گرافیکی و چیدمان صفحه اصلی |
| **استودیو سئو (`seo`)** | عنوان سایت، توضیحات متا، کلمات کلیدی، نویسنده و شبیه‌ساز نتایج جستجوی گوگل |
| **دسته‌ها و گزینه‌ها (`taxonomies`)** | ویرایش و افزودن گزینه‌های منوهای کشویی با به‌روزرسانی آبشاری خودکار در تمام بردها |
| **پشتیبان‌گیری (`backup`)** | بک‌آپ خودکار روی هاست (`api/data/backups/`، فقط N تای آخر، پیش‌فرض ۲)، اسنپ‌شات دستی، دانلود تکی هر نسخه، فایل کامل JSON و ایمپورت با سازگاری عقب‌رو |
| **امنیت و کلمه عبور (`security`)** | ایمیل بازیابی با تایید OTP، سؤالات بازیابی محلی (قفل ریست اضطراری)، تغییر رمز عبور، نشان حالت امن/محلی و صندوق ارسال SMTP با ایمیل تست |

## 🛠️ پشته فناوری و ساختار فایل‌های پروژه

* **هسته و رابط کاربری:** React 19 + Vite 8 + Tailwind CSS 3.4
* **امنیت داده‌ها:** DOMPurify Sanitization + Timing-Safe Token Comparison + Brute-Force Rate Limiter
* **خروجی PDF رزومه:** jsPDF + html2canvas
* **ویرایشگر متن غنی:** Word-Style WYSIWYG Editor + Mammoth DOCX Importer
* **تایپوگرافی:** وزیرمتن (`Vazirmatn`)

### 📁 درخت فایل‌های شاخص:
```text
├── README.md               # مستندات جامع دوزبانه (همین فایل)
├── QUICK_DEPLOY_FA.md      # راهنمای سریع آپلود + نصب + بک‌آپ (از این‌جا شروع کن)
├── DEPLOYMENT_GUIDE.md      # راهنمای تخصصی هاست ایران، cPanel و دامنه .ir
├── AI_INSTRUCTIONS.md       # دستورالعمل‌های معماری و پرامپت هوش مصنوعی
├── site-upload.zip         # فایل آماده آپلود روی هاست (با build-upload-zip.sh ساخته می‌شه)
└── resume-app/
```

## 🇬🇧 English Documentation & Quick Setup

### 🚀 Local Development (Quick Start):
1. **Clone or navigate** to the project repository:
   ```bash
   cd resume-app
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start local development server:**
   ```bash
   npm run dev
   ```
4. **Open in browser:** `http://localhost:5173`
5. **Default Admin Login:**
   - **Username:** `admin`
   - **Password:** `admin`

### 📦 Production Build & Web Deployment:
1. Generate the distribution bundle:
   ```bash
   npm run build
   ```
2. Compress the generated `dist/` directory into a `.zip` archive.
3. Upload and extract directly inside your web server's `public_html` directory (cPanel, DirectAdmin, Apache, or Nginx).
4. The included `.htaccess` file handles client-side SPA routing and Gzip compression automatically.
